# Items tools/deadcode.py reports that stay on purpose.
#
# One per line: <path> <item> <reason>. The path and the item are as the report
# prints them. An entry that matches nothing fails the scan, so delete an entry
# with the item it names.

# item of the API stays when no caller here uses it: list it, do not delete it.
